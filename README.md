# Mobile Automation Framework

Mobile test automation framework using Python, Pytest, Appium, and Android Emulator.

## Project Goal

This project demonstrates a professional SDET approach for mobile automation, including:

- Android mobile test automation
- Appium-based test execution
- Page Object Model
- Pytest test structure
- HTML reports
- CI/CD with GitHub Actions

## Current Stack

- Python
- Pytest
- Appium
- Android Emulator
- GitHub Actions
